# Threads Emmy

CRM d'Emmy : comptes Threads achetés, mis sur GeeLark, réchauffés pendant 3 semaines.
Interface en thaï (boutons EN / FR). Copie allégée de Threads HQ.

## Démarrer (Awen, une seule fois)
1. Ouvre le site, tape ton code : tu es admin.
2. Réglages > Proxy : colle le proxy + le lien de rotation.
3. Réglages > Numéros : colle les clés Hero / SMSPool / SMSOnline.
4. Réglages > Accès : crée le code d'Emmy (rôle VA).
5. Comptes achetés : colle la liste du vendeur.
6. Textes et photos : ajoute des photos pour les commentaires (semaine 2) et les posts (semaine 3).

## Tester en local
```bash
npm install
node dev/server.mjs        # http://localhost:8788
node dev/test-api.mjs      # serveur neuf
```
